# 中医门诊知识库与患者档案系统

这是一个本地桌面工具，用于维护和检索“辨证体系 / 病症分类 / 症状关键词 / 方剂方案”资料，并管理患者档案与就诊记录。程序只做资料记录、检索和展示，不做自动诊断、不做治疗保证、不做用药指导。

## 运行方式

源码运行：

```bash
python main.py
```

客户交付推荐打包为 Windows 免安装版：

```bash
pip install pyinstaller
pyinstaller -F -w main.py -n TCM_Knowledge_Search
```

打包后从 `dist` 文件夹取出 `TCM_Knowledge_Search.exe`，与 `data.json`、`patients.json` 放在同一个目录，并保留 `backup`、`exports` 文件夹。

## 数据文件

程序启动时会优先读取程序所在目录下的文件：

- `data.json`：知识库数据。
- `patients.json`：患者档案和就诊记录。
- 如果文件不存在，会自动创建默认文件。
- 如果格式错误，会提示用户检查 `data.json` 或从备份恢复，程序不会直接崩溃。

保存 JSON 时使用 UTF-8 和 `ensure_ascii=False`，便于中文路径和中文内容迁移。

## 搜索

搜索框支持输入证型名称、病症名称、症状关键词、方剂名称，也支持多个关键词组合。分隔符支持空格、中文逗号、英文逗号、顿号、分号和换行。

匹配结果按分数从高到低排序，主要评分规则：

- 证型/病症名称完全匹配：高分
- 证型/病症名称部分匹配：较高分
- 症状关键词匹配：按数量加分
- 完整症状描述匹配：加分
- 方剂名称匹配：加分
- 分类字段匹配：加分
- 治疗方案和备注匹配：低权重加分

## 数据维护

用户可以在界面中新增、编辑、删除记录。修改后标题栏会显示未保存标记，关闭软件前也会提醒是否保存。

点击“保存知识库”或“保存患者档案”时，程序会先将旧文件自动备份到 `backup` 文件夹，再写入新数据。

## 患者档案

“患者档案”页面支持：

- 新增、编辑、删除患者档案。
- 为每位患者新增、编辑、删除多次就诊记录。
- 按姓名、电话、症状、辨证记录、方剂参考等内容搜索患者。
- 在新增或编辑就诊记录时，输入症状关键词检索知识库，点击结果查看完整病症详情，再勾选相关病症。
- 勾选后可自动带入辨证记录、方剂参考和治疗方案说明。
- 已加入本次病历的病症会显示在“已加入本次病历”列表中，可选中后移除撤销。
- 复诊时可从患者历史病症中查看详情、选择并加入本次就诊记录。
- 打印当前患者的某一次就诊记录。

患者档案保存到 `patients.json`，与知识库 `data.json` 分开，方便备份和迁移。

## 打印

点击“打印当前病历”后，程序会先切换到打印预览页面。可点击“直接打印”尝试发送到 Windows 默认打印机，也可点击“打开病历单”先在浏览器中查看。如需修改内容，请返回编辑就诊记录。

## 页面结构

当前版本采用主窗口内页面切换：

- 患者档案列表
- 患者详情
- 患者信息编辑
- 就诊记录编辑
- 打印预览
- 知识库列表
- 知识库记录编辑

除系统提示、文件选择和确认删除等必要提示外，主要工作流不再依赖弹出的编辑子窗口。

如果自动打印失败，程序会自动打开生成的 HTML 病历单，用户可在浏览器中按 Ctrl+P 打印。若浏览器未自动打开，可点击“打开打印文件夹”，找到生成的 HTML 病历单后双击打开。

## 导入导出

- 导出数据：默认导出到 `exports` 文件夹，文件名包含日期时间。
- 导入数据：选择 JSON 文件后会替换当前数据，导入前会询问是否先备份当前数据。
