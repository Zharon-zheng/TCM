中医门诊知识库与患者档案系统 使用说明

一、如何启动软件

1. 解压收到的压缩包。
2. 打开解压后的文件夹。
3. 双击 TCM_Knowledge_Search.exe 即可使用。

如果您拿到的是源码版本，可在安装 Python 后运行：
python main.py


二、如何搜索知识库

1. 打开“方剂知识库检索”页面。
2. 在搜索框输入症状、证型、病症或方剂名称。
   例如：汗出、太阳中风、胸胁苦满、桂枝汤。
3. 多个关键词可以用空格、中文逗号、英文逗号、顿号、分号或换行分隔。
4. 点击“搜索”。
5. 在左侧查看匹配结果。
6. 点击左侧某条记录，可在右侧查看完整详情。


三、如何维护知识库数据

1. 点击“新增”。
2. 填写辨证体系、一级分类、证型/病症名称、症状关键词、方剂方案等内容。
3. 症状关键词可以用中文逗号、英文逗号、顿号、空格或换行分隔。
4. 点击“确定”。
5. 回到主界面后点击“保存知识库”。

编辑或删除知识库记录时，先在左侧选择一条记录，再点击“编辑”或“删除”，完成后点击“保存知识库”。


四、如何建立患者档案

1. 打开“患者档案”页面。
2. 点击“新增患者”。
3. 填写患者姓名、性别、年龄、电话、地址、过敏史、既往史等内容。
4. 点击“确定”。
5. 点击“保存患者档案”。


五、如何记录一次就诊

1. 在“患者档案”页面左侧选择患者。
2. 点击“新增就诊”。
3. 填写就诊日期、主诉、现病情况/症状记录、辨证记录、方剂参考、治疗方案说明、随访事项等内容。
4. 如果需要从知识库带入病症和方剂，可在“知识库联动”区域输入症状关键词，点击“检索病症”。
5. 在检索结果中点击某条病症，可先在“病症详情”区域查看完整症状、方剂和方案说明。
6. 确认后点击“勾选/取消当前”，或双击检索结果，勾选一个或多个病症。
7. 点击“加入勾选”，系统会把勾选的病症、对应方剂参考和治疗方案说明加入本次就诊记录。
8. 如果加入错误，可在“已加入本次病历”中选中对应病症，点击“移除已加入”撤销。
9. 复诊时，可点击“显示历史病症”，查看详情后勾选患者以前记录过的病症，再点击“加入勾选”。
10. 点击“保存并返回”。
11. 点击“保存患者档案”。

编辑就诊记录时，先选择患者，再选择右侧上方的某条就诊记录，然后点击“编辑就诊”。


六、如何搜索患者

1. 打开“患者档案”页面。
2. 在“患者检索”输入框中输入姓名、电话、症状、病症记录或方剂关键词。
3. 点击“搜索患者”。
4. 在左侧选择患者，右侧会显示患者档案和就诊记录。


七、如何打印病历

1. 打开“患者档案”页面。
2. 先选择患者。
3. 再选择一条就诊记录。
4. 点击“打印当前病历”。
5. 软件会切换到“打印预览”页面，用于确认本次打印内容；如需修改，请返回编辑就诊记录。
6. 点击“直接打印”后，软件会生成一份表格版 HTML 病历单，并尝试发送到 Windows 默认打印机。
7. 如果自动打印失败，软件会自动打开病历单文件，可在浏览器中按 Ctrl+P 打印。
8. 也可以点击“打开病历单”，先在浏览器中查看，再手动打印。
9. 如果浏览器没有自动打开，可点击“打开打印文件夹”，找到生成的 HTML 病历单后双击打开。


八、如何备份数据

1. 软件每次点击“保存知识库”或“保存患者档案”时，会自动把旧文件备份到 backup 文件夹。
2. 备份文件名包含日期和时间，方便查找。
3. 也可以点击“导出知识库”或“导出患者档案”，手动导出当前数据。
4. 导出的文件默认保存到 exports 文件夹。


九、如何迁移到另一台电脑

1. 推荐将整个软件文件夹复制到新电脑。
2. 至少需要复制 TCM_Knowledge_Search.exe、data.json 和 patients.json。
3. 双击 TCM_Knowledge_Search.exe 即可继续使用。


十、注意事项

1. 不要随意删除 data.json，它保存了当前知识库数据。
2. 不要随意删除 patients.json，它保存了患者档案和就诊记录。
2. 如果数据异常，可从 backup 文件夹中选择较新的备份文件恢复。
3. 恢复知识库时，可将 data 备份文件复制出来并改名为 data.json。
4. 恢复患者档案时，可将 patients 备份文件复制出来并改名为 patients.json。
5. 本系统仅用于门诊资料记录、患者档案管理与知识库检索，不作为自动诊断、治疗保证或用药指导。
6. 软件只保存和展示用户录入的资料，不进行自动医学判断。


十一、便携版文件夹建议结构

TCM_Knowledge_Search_Portable/
  TCM_Knowledge_Search.exe
  data.json
  patients.json
  README_使用说明.txt
  backup/
  exports/


十二、打包说明（给交付人员）

本程序只使用 Python 标准库。若需打包 Windows 免安装版，可先安装 PyInstaller：

pip install pyinstaller

在 main.py 所在目录运行：

pyinstaller -F -w main.py -n TCM_Knowledge_Search

整理交付文件夹：

1. 从 dist 文件夹取出 TCM_Knowledge_Search.exe。
2. 将 TCM_Knowledge_Search.exe、data.json、patients.json 放在同一个文件夹。
3. 新建 backup 和 exports 文件夹。
4. 放入 README_使用说明.txt。
5. 将整个文件夹压缩后发给客户。

注意：data.json 和 patients.json 不需要打包进 exe，应放在 exe 同级目录，方便客户备份、替换和迁移。
